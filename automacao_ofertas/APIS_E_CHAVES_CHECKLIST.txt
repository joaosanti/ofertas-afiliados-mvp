CHECKLIST DE APIs E CREDENCIAIS - OFERTAS AFILIADOS
===================================================

Arquivo de referencia rapida para configurar chaves/API no projeto local Python.
Projeto: automacao_ofertas

1) MERCADO LIVRE
-----------------
Portal dev:
https://developers.mercadolibre.com.br/

Documentacao:
https://developers.mercadolibre.com.br/pt_br/api-docs-pt-br

Credenciais para obter:
- MELI_APP_ID
- MELI_APP_SECRET
- MELI_REDIRECT_URI (registrar no app)

Variaveis no .env:
- MELI_APP_ID=
- MELI_APP_SECRET=
- MELI_REDIRECT_URI=
- MELI_ACCESS_TOKEN=
- MELI_REFRESH_TOKEN=
- MELI_SITE=MLB
- MELI_QUERY_TERMS=fone bluetooth,air fryer,notebook
- MELI_LIMIT_PER_QUERY=15

Fluxo OAuth no projeto:
- GET  /integrations/meli/oauth/url
- POST /integrations/meli/oauth/exchange
- POST /integrations/meli/oauth/refresh

2) TIKTOK
---------
Portal developers:
https://developers.tiktok.com/

Portal TikTok Shop partner/open api:
https://partner.tiktokshop.com/

Credenciais para obter:
- TIKTOK_APP_ID
- TIKTOK_APP_SECRET
- Tokens OAuth/Shop conforme seu tipo de conta

Variaveis no .env:
- TIKTOK_APP_ID=
- TIKTOK_APP_SECRET=
- TIKTOK_AFFILIATE_TAG=
- TIKTOK_FEED_URL=

3) AMAZON
---------
Associates (afiliado):
https://affiliate-program.amazon.com/

PA-API docs:
https://webservices.amazon.com/paapi5/documentation/

Credenciais para obter:
- AMAZON_ACCESS_KEY
- AMAZON_SECRET_KEY
- AMAZON_PARTNER_TAG

Variaveis no .env:
- AMAZON_ACCESS_KEY=
- AMAZON_SECRET_KEY=
- AMAZON_PARTNER_TAG=
- AMAZON_AFFILIATE_TAG=
- AMAZON_FEED_URL=

4) SHOPEE
---------
Afiliados BR:
https://affiliate.shopee.com.br/

Open Platform:
https://open.shopee.com/

Credenciais para obter (quando liberadas):
- SHOPEE_API_KEY
- SHOPEE_API_SECRET
- partner/shop id e token OAuth

Variaveis no .env:
- SHOPEE_API_KEY=
- SHOPEE_API_SECRET=
- SHOPEE_AFFILIATE_TAG=
- SHOPEE_FEED_URL=

5) EXECUCAO RAPIDA
------------------
Rodar API:
uvicorn app.main:app --reload --port 8010

Rodar coleta:
curl -X POST http://127.0.0.1:8010/collect/run

Healthcheck:
http://127.0.0.1:8010/health

6) OBS
------
- Mercado Livre ja esta com integracao real (publica + OAuth).
- Shopee/Amazon/TikTok estao em modo FEED_URL para conectar seu pipeline oficial.
- Quando tiver as credenciais finais dessas 3 plataformas, o proximo passo e implementar auth nativa de cada uma no coletor.
